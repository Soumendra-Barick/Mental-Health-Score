# 🧠 Mental Health Signal — Student Wellness Analytics

A machine learning-powered web application that analyzes a user's daily habits, screen time, academic lifestyle, physical activity, sleep, and stress levels to generate a predicted mental health score from **0 to 10**.

The project is designed as an informational and educational tool to help users understand how different lifestyle and digital habits may relate to their overall mental wellness.

> ⚠️ **Disclaimer:** This application is for informational and educational purposes only. It is not a clinical assessment or medical diagnostic tool and should not replace professional mental health advice.

## 📌 Project Overview

**Mental Health Signal** is a machine learning-based Student Wellness Analytics application.

The application analyzes different aspects of a user's daily routine, including:

- 👤 Personal profile
- 🎓 Academic level
- 📱 Social media and digital habits
- ⏱️ Daily screen time
- 🔓 Daily phone unlocks
- 📚 Study hours
- 🏃 Physical activity
- 😴 Sleep duration
- 😰 Perceived stress level

Based on the provided information, the machine learning model generates a predicted **mental health score from 0 to 10**.

The application is intended to provide a quick informational signal based on the user's daily lifestyle and habits.
